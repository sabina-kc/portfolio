# Security Policy

## Supported Versions

This is a personal portfolio site. Only the latest version deployed from the
`main` branch is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest (`main`) | :white_check_mark: |
| older commits   | :x:                 |

## Reporting a Vulnerability

If you discover a security vulnerability in this repository (for example, a
dependency vulnerability or an XSS issue in the site), please report it
privately rather than opening a public issue:

- Use GitHub's [private vulnerability reporting](../../security/advisories/new)
  feature on this repository, or
- Reach out via the contact information listed in the [README](README.md).

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce it
- Any suggested remediation, if known

You can expect an acknowledgment within a few days. Since this is a personal,
low-traffic site, response times may vary, but all reports are taken
seriously and addressed as soon as possible.
